# Текстовые игры с LLM

## Технические требования

1. Python 3.12.8
2. uv
3. Если нужны REST-эндпоинты - FastAPI
4. Если нужен консольный скрипт - он должен поддерживать 1) цветной вывод текста 2) форматирование markdown 3) tui с меню для выбора, как codex-cli, opencode, claude итд
4. Pydantic
5. Запуск на проде через Dockerfile, установка зависимостей через uv
6. Makefile с командами make docker-build, make docker-run, make docker-restart, make docker-stop, make docker-rm, make docker-update (=make docker-stop && make docker-rm && make docker-build && make docker-run)
7. Номер порта должен определяться параметром SERVICE_PORT
8. Краткий README.md с кратким описанием продукта, описанием эндпоинтов (вход, выход, пример curl, внутренняя логика), примерами запуска и описанием параметров
9. Параметры через load_env из .env-файла и переменных окружения
10. Пиши prod-like код, простой и поддерживаемый, без лишних усложнений и воркэраундов
11. Все доработки и фиксы делай по принципу минимальных изменений в коде
12. Избегай "костылей" - выноси константы в отдельный модуль, переиспользуй одинаковые константы и т.д.

## Бизнес-требования

Сейчас реализуется одна игра - "Выйди из тюрьмы". Но механизм должен легко расширяться на несколько

1. Запускается консольный скрипт, если игр больше одной - вопрос "выбери номер игры" и нумерованный список игр
2. "Выберите сложность игры: 1 - очень легко, 10 - очень сложно"
3. Игра "Выйди из тюрьмы":
   1. Игрок сидит в тюрьме
   2. Его охраняет стражник - LLM, выполняющий обычные обязанности стражника. Других сотрудников рядом нет (выходной, ночь, все дома)
   3. Игрок может свободно общаться с LLM, его цель - уговорить стражника выпустить игрока из тюрьмы
   4. Стражник тоже свободно общается с игроком от нечего делать. У него есть tool "release" - выпустить игрока (без параметров)
   5. Если стражник вызвал tool "release" - игрок на свободе, он выиграл
   6. Сложность игры влияет на то, насколько сложно убедить охранника - от нее зависит его промпт
   7. При победе выводится подзравление и красивая ASCII-картинка
